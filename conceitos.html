• A tag <footer> serve para fazer o rodapé do site ou página que você está desenvolvendo.
  • A tag <header> seria o cabeçalho do site onde fica o título e etc.
  • A tag <div> é uma divisão dentro de uma seção para fazer uma lista ou colocar imagens.
  • A propriedade color serve para "pintar" as letras de uma frase.
  • A propriedade background-color serve para pintar o fundo do site, seção ou div e por aí vai.
  • A propriedade text-aling:center serve para colocar os textos no centro do site.
